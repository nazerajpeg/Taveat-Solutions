# Taveat Solutions — Security Framework

A Python-based security framework covering anomaly detection, PII safeguarding, input validation, and ML-driven threat improvement.

## Modules

| File | Purpose |
|---|---|
| `main.py` | Entry point and usage examples |
| `config.py` | Configuration parameters |
| `models.py` | Core data structures |
| `anomaly_detection.py` | Behavioural analysis and anomaly detection |
| `pii_safeguard.py` | PII identification and protection |
| `input_validator.py` | Input sanitisation and validation |
| `ml_improvement.py` | ML-based threat detection improvements |
| `notification_service.py` | Alert and notification delivery |
| `admin_dashboard.py` | Admin interface |

## Getting Started

```bash
pip install -r requirements.txt
python main.py
```
